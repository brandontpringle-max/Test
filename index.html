Beginner Strength + 5K

Cardio

Estimated 1-rep max is worked out from your best set (3 reps at 60 kg ≈ 66 kg). Lifts run in 4-week blocks. Each block, aim for about 5 kg more than the last one.

    9-week plan

    Tap a run to mark it done or not done.

    How each session works

    1. 5–10 min stretch and warm-up.
    2. Main compound lift first (bench, squat, overhead press or deadlift).
    3. Accessory exercises.
    4. Superman holds for the lower back.
    5. Then the Couch to 5K run as extra cardio.

    Rules

    • Mon–Fri training, Sat and Sun rest.
    • Start with really light weights: 3 sets of 5–10 reps. Good form comes first.
    • When all 3 sets hit the top of the rep range with good form, add a little weight next time.
    • Lower back: do Superman holds every day, at home too. Stop if anything hurts sharply. With an old back injury, see a GP or physio if pain keeps coming back.
    • Train in pairs if you can. It keeps you both motivated.
